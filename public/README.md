# 📁 Assets Públicos

Esta pasta contém os arquivos estáticos do projeto.

## 🎨 Logo

**IMPORTANTE:** Salve sua logo aqui com o nome `logo.png`

### Caminho esperado:
```
public/
  └── logo.png  ← Sua logo dadosIA aqui
```

### Formato recomendado:
- ✅ PNG com fundo transparente
- ✅ Tamanho: 512x512px ou maior
- ✅ Proporção 1:1 (quadrado)

### Uso no código:
A logo é referenciada como `/logo.png` em:
- `components/FirebaseApp.jsx` (Sidebar - 80x80px)
- `components/SimpleLanding.jsx` (Header - 48x48px, Hero - 120x120px)
